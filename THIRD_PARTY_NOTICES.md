# Créditos e materiais de terceiros

Este repositório publica uma curadoria de configurações, documentação e uma amostra sintética. Pacotes VSIX, fontes e executáveis são obtidos pelas suas distribuições oficiais e não são incluídos aqui.

## Vesper

- Autor e publicador: Rauno Freiberg.
- [Código e paleta de origem](https://github.com/raunofreiberg/vesper).
- [Marketplace](https://marketplace.visualstudio.com/items?itemName=raunofreiberg.vesper).
- Licença MIT: [aviso original](assets/licenses/vesper-MIT.txt).

A configuração parte da paleta Vesper e adapta o texto neutro, comentários, diffs e algumas superfícies. O nome Vesper identifica a extensão de origem; este repositório não é uma distribuição oficial dela.

## Symbols

- Autor e publicador: Miguel Solorio.
- [Código e ícones de origem](https://github.com/miguelsolorio/vscode-symbols).
- [Marketplace](https://marketplace.visualstudio.com/items?itemName=miguelsolorio.symbols).
- Licença MIT: [aviso original](assets/licenses/symbols-MIT.txt).

A imagem ilustrativa do README usa formas dos ícones do pacote Symbols 0.0.26 sobre uma montagem com a paleta do preset.

## Cascadia Code

- Projeto da Microsoft: [microsoft/cascadia-code](https://github.com/microsoft/cascadia-code).
- Licença da fonte: SIL Open Font License 1.1, conforme o projeto oficial.
- A fonte não é distribuída neste repositório. O preset a seleciona se ela estiver instalada e fornece um fallback no Windows.
