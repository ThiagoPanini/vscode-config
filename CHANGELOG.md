# Histórico de mudanças

## 1.1.0 2026-11-07

- Instalador Python autossuficiente, sem dependências externas, para VS Code Stable no Windows.
- Alternativa `.sh` para Git Bash, com o mesmo instalador Python embutido.
- Instalação de Vesper e Symbols pelo Marketplace usando a CLI oficial; provedores Python opcionais.
- Mesclagem de JSONC preservando preferências externas ao preset, comentários fora dos valores substituídos, BOM e finais de linha.
- Simulação sem gravação, backup exato, substituição atômica e conferência de alterações concorrentes.
- Opções para manter a fonte do terminal, usar Consolas ou indicar um arquivo de outro perfil.
- Testes isolados para mesclagem, idempotência e falhas; roteiro manual preservado.

## 1.0.0 2026-11-07

- Publicação inicial de Vesper Equilibrado com Symbols e pastas neutras.
- Preset visual separado dos módulos opcionais de Python e terminal.
- Alternativa de fonte para Windows sem instalação adicional.
- Roteiro manual pelo Marketplace e pelo editor de configurações.
- Blocos completos no README para copiar pelo navegador.
- Amostra sintética de Python, diagnóstico e instruções de reversão.
- Registro das versões de referência e créditos de terceiros.
